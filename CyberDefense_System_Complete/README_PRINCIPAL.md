## 🚀 Lancement Rapide

### Option 1: Lancement Automatisé (Recommandé)
```bash
python LANCER_SYSTEME.py
```

### Option 2: Lancement Manuel
```bash
# 1. Activer l'environnement virtuel
source cyberdefense_env/bin/activate  # Linux/Mac
# ou
cyberdefense_env\Scripts\activate     # Windows

# 2. Lancer le système
python minimal_start.py

# 3. Tester le système
python test_system_live.py
```

### Option 3: Installation Complète
```bash
# Windows
install_and_run.bat

# Linux/Mac
chmod +x install_and_run.sh
./install_and_run.sh
```
